# Rev.0.9 ステレオPCM・ソフトウェアDSP・3次1bit DSM音声デモ計画

2026-11-20更新。PCM入力からDSM出力までを本番FPGAイメージに組み込み、RTLシミュレーション・合成・配置配線のタイミング検査に合格した。このデモではSFC標準SPC700/S-DSPの8chと独立したカートリッジ音源を実機で実証する。[Rev.0.9追加音声仕様](../../audio.md)

## デモ構成

RISC-Vのゲーム固有コードは内蔵Flash上のcmixerを共通音声ライブラリとして利用し、16音をミキシングして16 bit・64 kHzのステレオPCMを生成する。音声素材は必要に応じて外部NORから供給し、音源ごとの再生・パン・ピッチはRISC-Vから直接制御する。FPGAは80 MHzの5相FIRで320 kHz・17 bitに変換する。その値を水晶由来の8 MHz側で25クロック保持し、左右独立の3次1 bit DSMへ渡す。DSM出力はPIN29/30から受動RCとMCP6002による約22 kHzのアクティブLPFを経てSFC AUDIO L/Rへ出力する。

FIRの250クロック枠、固定小数点モデルとの照合、8 MHzへのCDCとSTAは本番構成で確認した。RISC-Vは `0x60002000` のPCM FIFOへ左右16 bitを1ワードで書込み、`0x60002004` のSTATUSを確認し、`0x60002008` のCONTROLで再生を制御する。[音声仕様](../../audio.md) · [検証記録](../../verification/ahb-interface.md)

## 実装段階

| 段階 | 内容 | 完了条件 |
|---|---|---|
| A0 | PIN29/30に左右の3次DSMを割り当て、HSEの8 MHzで出力 | 本番のピン割り当てとクロック接続、RTLのビット密度を確認済み。基板上で出力と過入力時の復帰を測定する |
| A1 | 80 MHzの5相FIR、左右各17 bitの25クロック保持、非同期FIFOを統合 | 本番の250クロック枠、モデル照合、STAとLUT/FF/BRAM使用量を確認済み |
| A2 | 受動RC＋約22kHzアクティブLPF＋MCP6002を調整 | 26kHzまでの総合応答、38kHz以上のイメージ、SNR/SINAD/THD+N、左右分離、8MHz残留ノイズを測定 |
| A3 | cmixerによる16音PCMミキシング、音量・パン・ピッチ、SFC `$5001 COMMAND`とFIFOによる制御 | 64kHzでの16音連続再生、IRQ/FIFO、CPU占有率、アンダーランを測定 |
| A4 | cmixerの16音に多バンドEQ、ローパス/ハイパス、ディレイ/リバーブ/コーラス/リミッタ等の追加DSPを組み合わせる | 音声負荷とRAM・外部MEM帯域を計測 |
| A5 | cmixer 16音＋SFC標準S-DSP 8音の24音同時再生、Jetの3D起動ロゴとDSMジングルの同期、USB/microSDリソース供給 | SFC処理と独立音声の並行動作、起動診断、24音同時発音を確認 |

A3以降は16音を基本仕様とし、追加DSPとJet併用時の余裕をCPU負荷・RAM容量で測定する。長時間の音声は内蔵SRAM128KiBへの全量保存を前提にせず、外部NOR/SRAMアクセスではSFC共有MEMバスを調停する。

## 体験と測定

画面には各音源のパン、同時音数、EQ設定、PCM FIFO残量、CPU負荷を表示し、SFC側からRISC-Vに設定を送信する。16bit/64kHzステレオPCMの1秒分は256,000Bであり、音源と遅延バッファの容量管理を明示する。

1. 無音、低振幅・最大振幅の正弦波、周波数スイープで3次DSMの安定性と高周波ノイズを測る。
2. 12bit量子化FIR係数、17 bit信号幅、丸めの影響をソフトウェアモデルとRTLで比較し、補間・FIR・アナログLPFを合成した周波数特性を確認する。
3. DSM出力エッジの周期とクロックジッタ、左右同期、80 MHz→8 MHzのCDC、PCMのアンダーラン/復帰を測定する。
4. 実アプリでcmixer 16音、多バンドEQ、エフェクト、Jetによる3D描画、SFC画面更新を並行動作させ、性能を評価する。

基礎ROMマッピング・AHB通信・外部MEM所有権とFastROMの動作を優先し、DSPの仕様は[音声基本仕様](../../audio.md)に従う。
