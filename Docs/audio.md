# Rev.0.9 追加ステレオPCM音声・3次1bit ΔΣ（DSM）出力

2026-11-20更新。RISC-Vによる音源ミキシング・DSP処理と、FPGAによる**64kHz/16bitステレオPCM → 5倍線形補間 → 64タップFIR → 25倍線形補間 → 3次1bit DSM（8MHz）**を現行設計とする。FIRは96MHzのPLL由来演算クロック、DSM最終ビット出力は既存8MHz水晶由来のクロックを独立に使用する。外部配線は左右2本の音声出力PIN29/30を維持する。これは採用設計であり、回路合成・ピンフィッティング・クロック経路確認・実測は未実施である。

## 信号経路

```text
RISC-Vのゲーム固有アプリ＋共通Flashのcmixer（16音）／追加DSP
         ↓ 64kHz / signed 16bit stereo PCM
AHB → FPGA PCM FIFO／二重バッファ（CDC）
         ↓
5倍線形補間 64kHz → 320kHz（内部19bit）
         ↓
64タップ・線形位相対称FIR（320kHz、係数signed 12bit）
  └ 1基の20×12bit・4bit逐次乗算器を左右で時分割共有
    対称19bitサンプル2個を20bitで先行加算
    40bit程度の積和アキュムレータ → 丸めて19bit
         ↓ 320kHzの完成サンプルをCDCバッファで受け渡し
25倍線形補間 320kHz → 8MHz（内部19bit）
         ↓
左右独立の3次1bit DSM（8MHz、HSE水晶基準）
         ├→ AG32 PIN29（DAC0兼用デジタルIO）→ 受動RC → アクティブLPF（約22kHz） → MCP6002左 → SFC AUDIO L端子31
         └→ AG32 PIN30（DAC1兼用デジタルIO）→ 受動RC → アクティブLPF（約22kHz） → MCP6002右 → SFC AUDIO R端子62
```

## デジタル精度とFIR

| 項目 | 採用方針 |
|---|---|
| PCM入力 | 64kHz、signed 16bit、ステレオ |
| 補間前後の内部信号 | signed 19bit |
| 第1段 | 5倍線形補間（64→320kHz） |
| 中間FIR | 64タップ、320kHz、左右共通係数、線形位相対称 |
| FIR係数 | signed 12bit固定小数点（係数スケーリングは設計時に確定） |
| 対称サンプル加算 | 19bit + 19bit → signed 20bit |
| 乗算器 | **20×12bit符号付き、4bit逐次、1基を左右時分割** |
| 単項乗算結果 | 32bit |
| FIR積和累積 | 約40bitを設計基準とし係数絶対値和と丸めで確定 |
| FIR出力 | 丸め・飽和してsigned 19bit |
| 第2段 | 25倍線形補間（320kHz→8MHz） |
| 変調器 | 左右独立3次1bit DSM、8MHz |

FIR係数を左右対称とすることで各chの64タップを32回の対称サンプル加算・乗算に置き換える。ステレオ合計64乗算/320kHz周期となり、96MHzでは1周期300クロックを使用できる。係数12bitを4bitずつ3分割した場合、部分積演算には最低192クロックを要し、残る108クロックにメモリ読出し・対称加算・累積・状態遷移・出力確定を収めるスケジューリングを設計する。3クロック/積を達成できることは未確認であり、係数の符号拡張、積のシフト加算、乗算器のクリア/ハンドシェイク、RAMポート数を含めて96MHzのSTAとサイクル検証を行う。

第1段の線形補間による26kHz付近の高域減衰は、320kHz動作のFIRで必要量を補償する。38kHz以降のイメージ軽減もFIRで行うが、遮断をデジタルFIRだけで完結させない。最終的な帯域制限は約22kHzのアナログ・アクティブLPFとの総合特性で定める。12bit係数量子化後のパスバンド誤差・イメージ残留・丸め雑音・飽和をモデルで評価する。

## クロックドメインとDSM

AG32 PIN12/13に接続する8MHz水晶を、DSMの1bit出力タイミングの基準とする。8MHz/125=64kHzの整数比で出力サンプル時刻を規定し、PLLクロックのジッタを最終GPIO出力エッジへ直接伝えない設計とする。FPGAへのPLL非経由のHSEクロック供給経路（`PIN_HSE_OUT`等）はPrepare LOGICの自動生成トップとSupra Nativeで確認する。追加の水晶・専用クロック入力GPIOは計画しない。

FIRと第1段補間は96MHzの演算クロックで動作し、第2段補間・3次DSMは8MHzで動作する。クロック間は非同期FIFOまたは確実なハンドシェイク付き二重バッファで受け渡し、出力サンプルの時刻を8MHz側が決める。CPU/AHB由来のPCM供給にも同様のCDCを適用する。96MHzの生成可否と他のSoC PLL/USB設定との両立は実機クロックツリーで確認する。

3次DSMは量子化器1bit、内部積分器に必要なガードビットを設け、安定性が確認された係数・NTFで実装する。無音時のアイドルパターン、過大入力、クリッピング、リミットサイクル、オーバーフローと回復をシミュレーション・測定する。内部19bitはPCM/補間/FIRの信号幅であり、DSM積分器の必要幅を19bitに制限しない。

## アナログ出力

PIN29/PIN30はDSM時にDAC機能を無効化してFPGAデジタル出力とする。出力はMCP6002を用いた左右独立のアクティブLPF（カットオフ約22kHz）へ接続し、8MHzのスイッチング成分をオペアンプ入力へ過大に与えないよう手前に受動RC段を置く。LPFの次数、抵抗・容量、ゲイン、直流バイアス、出力振幅、負荷、電源ノイズ、クロストークは回路設計・実測で確定する。アナログ回路全体が決める可聴帯域特性と26kHz付近の余裕を評価する。

SFC標準SPC700/S-DSPの8chとは独立した追加ステレオ音声として出力し、標準音声全体をRISC-V側でEQする構成ではない。

## RISC-Vの音源・DSPとメモリ

標準PCMミキサーは内蔵Flashに共通ライブラリとして配置するcmixerとし、16音の同時再生、音源別音量・パン・ピッチ、ループ、線形補間を担当する。cmixerの出力は64kHz・signed 16bit・インターリーブ・ステレオPCMとし、5バンドEQ、ローパス/ハイパス、ディレイ/リバーブ、コーラス、リミッタ等は必要なものをRISC-Vの追加ソフトウェアDSPとして実装する。cmixer自体にはこれらのエフェクトは含まれない。64kHz・16bit・ステレオの無圧縮PCMは1秒あたり256,000Bであり、ゲーム実行コードとバッファが内蔵SRAM128KiBを共有するため、長時間の音声サンプルやディレイはすべてを内蔵SRAMへ格納しない。外部NOR/SRAMを使う場合はSFCとMEMバスを共有するのでバス調停を行う。

cmixerは各音源に16bitステレオの512サンプル・1,024Bバッファを持ち、16音構成では音源管理と32bit合成バッファだけで概ね20KiBを要する。音声素材・PCM出力二重バッファ・追加DSP領域は別途確保する。長時間のサンプルは外部NOR等から供給し、内蔵SRAMへの全量展開を前提としない。SFCからの制御は`$5001 COMMAND`・FIFO・IRQを使い、`$5000 CPU_CONTROL`によるゲーム固有処理停止中も共通ファームウェアと電源断退避を維持する。PCM FIFOのアンダーラン時の処理も定義する。

SFCのSPC700/S-DSP 8音とRISC-V/cmixerの16音を併用すると合計24音となる。S-DSPとDSMは独立の出力経路であり、全24音を同一のソフトウェアEQに通す構成ではない。OS起動時には短いcmixerジングルをDSMから出力し、Jetの3Dロゴと同期させる。

## 実装・測定

1. ROM/AHB/MEM調停回路を含めて96MHz FIRと8MHz DSMのクロック供給、PIN29/30 GPIO出力、合成LUT/FF/BRAM、STA、CDCを確認する。
2. 20×12bitの4bit逐次乗算器と対称64タップFIRを固定小数点モデルと突き合わせ、300クロック/320kHz周期でステレオの処理が完了するか検証する。
3. 3次DSMの安定性、8MHzビット列、64kHzサンプル周期、無音時のアイドルパターン、クリッピングからの復帰を測る。
4. FIRと約22kHzのアナログLPFの合成周波数特性、26kHzまでの応答、38kHz以上のイメージ、SNR/SINAD、THD+N、左右分離、EMI、出力振幅を測定する。
5. cmixer 16音、追加DSP、Jet 3D描画を同時使用した際のRISC-V負荷、サンプル欠落、内部SRAM容量、外部MEM帯域を測定する。
