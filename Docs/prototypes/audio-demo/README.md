# Rev.0.9 ステレオPCM・ソフトウェアDSP・1bit DSM音声デモ計画

作成: 2026-11-20。状態: **デモ構想・性能目標（未実装・未測定）**。本計画は[Rev.0.9追加音声仕様](../../audio.md)に基づく。SFC標準SPC700/S-DSPの8chとは独立したカートリッジ音源を使用し、AG32のRISC-V演算能力とFPGAの高速デジタル出力による音声処理を実演する。

## 1. デモの狙い

単なるモノラル／ステレオPCM再生の比較にとどまらず、**音源別パン、8～16ch多重PCM、動的EQ、フィルタ、空間系エフェクト**を操作できるようにする。ゲーム画面上でEQカーブや使用中チャンネル数を表示し、処理オン／オフによる音の変化とCPU負荷を同時に確認する。

出力は既存8MHz水晶を基準とする**64kHzステレオPCM→8MHzの1bit DSM L/R（OSR=125）**を目標とする。LQFP100の**PIN29/PIN30をDAC0/DAC1兼用IOのFPGAデジタル出力として使用**し、既存のLPF→MCP6002→SFC外部AUDIO L/R経路を活用する。別の音声端子やクロック入力端子を追加しない。従来の10bit DAC・32kHz方式は比較対象とし、DSM用LPFの定数・段数は測定結果に基づいて設計する。

## 2. 音声デモの段階

| 段階 | 実装内容 | 完了条件 |
|---|---|---|
| A0 | FPGAのPIN29/PIN30 GPIO出力、HSE 8MHzクロック、DSM一次変調器、64kHz PCM更新 | 左右2本のビットストリーム・周波数・周期を確認 |
| A1 | 二次DSM、無音／正弦波／スイープ再生、DSM用LPF・MCP6002調整 | 再生と左右分離を実測、10bit DAC方式と特性比較 |
| A2 | 8ch PCMミキシング、音量・ステレオパン制御 | 64kHzで連続再生し、サンプル欠落・CPU占有率を記録 |
| A3 | 最大16chを試験、5バンドEQ、ローパス／ハイパス、パラメータリアルタイム変更 | フィルタ係数更新・連続再生・処理負荷・音質を確認 |
| A4 | 簡易リバーブ／ディレイ／コーラス／リミッタ | 効果音とBGMの個別エフェクト処理を実演し、RAM消費量を記録 |
| A5 | SFC標準8chとの同時再生、ゲーム場面に応じた動的エフェクト、USB／microSD音源 | SFC側制御、外部アセット読出しと音声継続性を検証 |

A2以降の同時音声数とDSP機能は**実測で決める目標値**であり、CPU負荷とメモリ制約を確認せず実装保証値とはしない。標準SPC700の音声はSFC本体側で再生し、追加音源側の処理とは独立させる。

## 3. 体験・表示項目

- **ステレオ定位デモ:** 8～16の音源が左右に移動する様子をSFC画面に表示し、各音源のパンと音量をRISC-V側で計算する。
- **EQ・フィルタ比較:** 5バンドEQの各帯域ゲインを操作し、ローパス／ハイパスを切り替える。ゲーム中の水中・洞窟表現を模したローパス／リバーブの効果を比較する。
- **DSPエフェクト比較:** 直接音と加工音を切り替え、ディレイ、リバーブ、コーラスを順に検証する。エフェクトの入力・出力レベルも画面で確認する。
- **DAC／DSM比較:** 10bit DAC出力と1bit DSM出力の正弦波、スイープ、無音時を測定し、分解能の期待値ではなく実測SNR/SINAD/THD+N、ノイズフロア、左右分離を比較する。

## 4. クロック・データ転送の設計検証

`8,000,000/125=64,000`を用い、FPGAが同一HSEクロックからDSM変調とPCM更新イベントを生成する。RISC-VはCPU／AHBクロックでPCMを生成し、クロックドメイン間FIFOまたは二重バッファを通じてFPGAへ渡す。タイマーやAHBアクセスの揺らぎによってDSM出力タイミングを変化させない。

FPGAとPIN29/30の直接駆動、`PIN_HSE_OUT`等からの8MHzクロック供給、Prepare LOGICでの実際のピン・AHB接続はSupra Native合成・配置配線で確定させる。FPGAのROMマッピング、FIFO、共有MEM所有権制御を優先し、既存のSFC通信やFastROM動作に悪影響が出ないことを確認する。

長時間のリバーブには遅延バッファが必要になる。64kHz・16bit・ステレオの1秒分は256,000Bであり、AG32内蔵SRAM128KiBへ音声データを全量保持する前提にしない。外部SRAMを使用する場合はSFCと共有する8bit MEMバスの所有権と待機時間を計測する。

## 5. 測定項目と評価手順

1. 8MHz DSMビットストリーム、64kHz更新周期、L/R同期、無音時・最大振幅時の安定性をロジックアナライザとオシロスコープで確認する。
2. LPFの周波数応答、出力レベル、SNR/SINAD、THD+N、クロストーク、ポップノイズ、電源ノイズ、高周波残留を計測する。
3. 8ch／16chとEQ・エフェクト併用時のCPUサイクル、処理時間、リングバッファ残量、アンダーラン、SRAM使用量を測定する。
4. SFC側`$5000`通信窓／FIFO経由で音源・EQ・エフェクトを制御し、PCM更新とゲーム処理の同時動作を検証する。
5. 既存10bit DAC案を比較基準として残し、DSM実装の部品数・LPF変更・性能・ノイズを評価する。

このデモは本体Rev.0.9の基本メモリ制御・通信機構が完成した後に実施する。回路規模の合成・測定結果が得られるまで、音声品質や同時音源数を達成済みとは記載しない。
