# Rev.0.9 — RISC-V音源・cmixer・DSP

## RISC-Vの音源・DSPとメモリ

標準PCMミキサーは内蔵Flashに共通ライブラリとして配置するcmixerとし、16音の同時再生、音源別音量・パン・ピッチ、ループ、線形補間を担当する。cmixerの出力は64kHz・signed 16bit・インターリーブ・ステレオPCMとし、5バンドEQ、ローパス/ハイパス、ディレイ/リバーブ、コーラス、リミッタ等は必要なものをRISC-Vの追加ソフトウェアDSPとして実装する。cmixer自体にはこれらのエフェクトは含まれない。64kHz・16bit・ステレオの無圧縮PCMは1秒あたり256,000Bであり、ゲーム実行コードとバッファが内蔵SRAM128KiBを共有するため、長時間の音声サンプルやディレイはすべてを内蔵SRAMへ格納しない。外部NOR/SRAMを使う場合はSFCとMEMバスを共有するのでバス調停を行う。

cmixerは各音源に16bitステレオの512サンプル・1,024Bバッファを持ち、16音構成では音源管理と32bit合成バッファだけで概ね20KiBを要する。音声素材・PCM出力二重バッファ・追加DSP領域は別途確保する。長時間のサンプルは外部NOR等から供給し、内蔵SRAMへの全量展開を前提としない。SFCからの制御は`$5001 COMMAND`・FIFO・IRQを使い、`$5000 CPU_CONTROL`によるゲーム固有処理停止中も共通ファームウェアと電源断退避を維持する。PCM FIFOのアンダーラン時の処理も定義する。

SFCのSPC700/S-DSP 8音とRISC-V/cmixerの16音を併用すると合計24音となる。S-DSPとDSMは独立の出力経路であり、全24音を同一のソフトウェアEQに通す構成ではない。OS起動時には短いcmixerジングルをDSMから出力し、Jetの3Dロゴと同期させる。

PCM FIFO・FIR・DSMレジスタと実機音声計測は[FPGA音声仕様](../fpga/audio.md)、アプリケーションABIは[共通ファームウェア](application.md)を参照する。
