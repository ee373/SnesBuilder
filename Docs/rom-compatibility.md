# 既存SFC ROMの対応

Rev.0.7 / 基本設計段階

## 1. 方針

本カートリッジの目的は新規SFCゲームの開発であり、既存ROM対応は副次的機能とする。HiROM・ExHiROMの切替と1MiB単位のハードウェアROMミラーを用いる。1MiB未満のROMは元のミラー規則に従って1MiBの物理イメージへ複製し、1MiB以上の整数MiB容量は必要なブロックのみNORへ書き込んでハードウェアミラーを利用する。既存拡張チップの互換性は完成条件に含めない。

ROMヘッダ、実ファイル容量、対象基板のマッピングに基づきROM_BLOCKS_M1（1MiBブロック数−1）とEXHIROM_ENABLEを設定する。HiROMの有効容量は1～4MiB、ExHiROMは1～8MiBとし、整数MiBでない容量は元のミラー規則に従い次の1MiB境界までソフトウェアで補完する。単純な末尾パディングは行わない。HiROM/ExHiROMからの変換を要しない場合はヘッダ・チェックサムも保持する。

SRAMは128KiB固定配線とし、HiROM型/ExHiROM型デコードは対象基板に合わせる。小容量SRAMミラーへの依存は個別パッチで扱う。必要に応じARM通信領域を無効化する。FastROM未対応時のMEMSEL依存も個別検証する。

## 2. ROMローダ

64KiB内部SRAMにROM全体を展開する必要はない。microSDから数KiBずつ読み、NORへストリーミング書き込みする。同一ROMキャッシュ時は消去・書き込みを省略する。必要な再配置・複製・チェックサム修正はARMまたはPC上で実行し、ゲーム固有の機械語解析とパッチ作成はPC側で行う。

## 3. ゲーム別パッチ

CRC32等でROMイメージを識別し、microSDのsystem/patches/からパッチを選択する。共通ファームウェア更新なしで追加可能とする。変換ツール、パッチ形式、互換性試験は未実装。SFC側BIOSはPSoC内蔵Flashに保持し、起動時に外部SRAM末尾8KiBへ展開する。NORの8MiBはゲームとリソースに使用する。
