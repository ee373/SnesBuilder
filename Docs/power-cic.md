# 電源・バッテリーバックアップ・CIC

Rev.0.8 / 基本設計段階

## 1. 電源構成

カートリッジはSFC本体から供給される5Vで動作する。PSoC内部コアは内蔵レギュレータを使用する想定とし、基板上に3.3Vを生成する。

| 電源 | 供給先 |
|---|---|
| 5V | PSoC、SFC側VDDIO、CIC、音声アンプ、8T245 VCCB、PSoCの5Vドメイン |
| 3.3V | NOR、SRAM、microSD、AG256SL100（VDDC・VDDIO1/2・VDDF33）、8T245 VCCA、LVC245A×5、メモリ側VDDIO |
| CR2032 | 電源切断時のSRAM |

VDDIO0/3を5V、VDDIO1/2を3.3Vとする詳細割り当て案は[hardware.md](hardware.md)を参照する。AG256 MEM_BUS_OE、8T245 /OEとLVC245A #1 /OE、メモリ制御は、PSoC未初期化中も安全な状態を維持する。3.3Vレギュレータの第一候補はMicrochip **MCP1825S-3302E/DB（3.3V・500mA・SOT-223）**とし、手はんだ可能な外部リード型を採用する。入力・出力直近の4.7µFを基本とし、最大消費電流、熱設計、起動過渡、実装基板での安定性を検証する。

USBはSFC本体から給電する自己給電型を基本とする。USB VBUSとSFC 5Vは直接接続せず、VBUS検出を行う。SFC電源OFF時を含め、逆給電を防ぐ回路を設計する。

## 2. SRAMバックアップ

通常は3.3Vで給電し、電源切断時はCR2032によってSRAMの内容を保持する。

| 型番 | 用途 |
|---|---|
| MAX40200AUK+T | 通常電源側の理想ダイオード |
| BAS116 | 電池側低漏れ電流ダイオード |
| TPS3839K33DBZR | 電源電圧監視 |
| CR2032 | バックアップ電源 |
| CR2032ホルダー | 電池交換 |

```text
3.3V -------- MAX40200 ------+
                             |
CR2032 ------ BAS116 --------+---- SRAM VCC

3.3V -------- TPS3839 ------------ SRAM CE2
                   電源監視
```

通常電源側の理想ダイオードでSRAMのVCC低下を抑える。電源監視ICによってCE2を無効化し、電源切断時のデータ破損を防止する方針である。

この図は概念回路であり、CE2が電源喪失時にも確実にLowに維持されるか、監視しきい値、出力方式、逆給電、漏れ電流、書き込み禁止タイミング、SRAMの電圧条件を検証する必要がある。必要なプルダウン等は詳細設計で決定する。

SRAM内セーブデータは次の起動時またはゲーム切り替え時にmicroSDへ同期する。詳細は[firmware.md](firmware.md)を参照する。

## 3. CIC

| 項目 | 仕様 |
|---|---|
| 型番 | PIC12F629-I/SN |
| メーカー | Microchip Technology |
| パッケージ | SOIC-8 |
| 用途 | SFC CIC認証 |
| ファームウェア | SuperCIC Keyを利用する想定 |
| 書き込み | ICSP端子またはテストパッド |

CICはPSoCと独立して動作し、PSoCの初期化と並行して認証を行える構成とする。

CICの信号接続、ファームウェア、初期化所要時間、SFC本体リセット解除との関係は実機で検証する。PSoC初期化前からSFCリセットを保持する専用回路は必須とはせず、PSoC起動後にP15[1]からSFC /RESETを再アサートしてBIOS展開完了まで保持する方式を採用候補とする。P15[1]は入力監視兼オープンドレインLow駆動・High-Z解放とし、本体側の駆動・プルアップ・CICとの競合がないことを確認する。初回先行起動中の未初期化バス出力は非選択・High-Zとして安全を確保し、必要に応じてリセットパルス幅を検証する。

## 4. PSoC電源・デバッグ接続の詳細

VDDA/VDDDを5V、VDDIO0/3を5V、VDDIO1/2を3.3Vとする。内部レギュレータのVCCA/VCCDは外部給電せず、規定のコンデンサとVCCD間接続を実装する。P15[3]はBOOT_MODE専用の5V出力へ変更し、LVC245A #5を通じてAG256へ接続する。AG256のMEM出力用OEはP4[7]からLVC245A #5を介して制御し、CFG0 ARM_MEM_ENABLEとの組合せで隔離状態を定義する。8T245とLVC245A #1の/OEには3.3Vプルアップ、MEM /CE・/OE・/WEには非選択用プルアップを設ける。PSoC MEM4制御線はAG256の入力に接続する。SWDの基準電圧は3.3V、基板別給電、XRES専用端子を使用する。電源端子処理、デカップリング、USB VBUS検出、専用XRESの電気条件はAN61290とデータシートに基づく回路図レビューで確定する。CR2032は外部SRAM専用とする。


## 5. 周辺電源部品・受動部品の選定（2026-11-17）

試作は手はんだ実装とし、ICは外部にリードが見えるパッケージのみを対象とする。受動部品は0805を基本、4.7/10µFは1206、5V入口のバルクは1210を使用する。正式な型番候補・数量別参考単価は[production.md](production.md)の第2節に記載する。回路図確定後に受動部品の個数を更新する。

| 系統・用途 | 採用候補 | 実装上の扱い |
|---|---|---|
| SFC 5V入口のバルク | **Samsung CL32A476KOJNNNE、47µF、16V、X5R、1210 ×1** | 公称47µF。5V DCバイアス時の参考実効容量はメーカー曲線の読み取りによる約29µF。基板が曲がるエッジ近辺を避ける |
| LDO入力・出力 | Samsung CL31B475KAHNFNE、4.7µF、1206 ×各1 | LDO近傍に実装し、全3.3Vレールの容量・起動挙動を確認する |
| NOR近傍 | 0.1µF（電源端子側）＋4.7µF（局所バルク） | 接続点・必要数はピン別回路図で確定する |
| microSD近傍 | 0.1µF＋10µF | SPI信号のESDをUSBLC6-4SC6で保護する候補 |
| PSoC VCCD/VCCA | 1µF各1 | 内蔵レギュレータ出力。外部給電せずAN61290に沿って配線する |
| その他ICの電源 | 0.1µFの0805 MLCC | PSoC、AG256、8T245、LVC245A×5、SRAM、PICなど各電源端子に近接配置 |
| USB D+/D− | 22Ω（±1%・0805）各1 | PSoC USBIOの近傍に直列実装。USB ESDはUSBLC6-2SC6 |
| USB VBUS検出 | 10kΩ直列＋100kΩ GND側 | 5V VBUSでP12[3]に約4.55V。SIOの入力モード・無給電許容・逆給電を確認 |
| microSD制御 | /CS=10kΩプルアップ、CLK=47kΩプルダウン | 3.3V側。GPIO追加なし、カード検出端子は未使用 |
| LVC245A #1 /OE・8T245 /OE | 各3.3Vプルアップ | 起動時と所有権切替中のMEMアドレス/データをHigh-Zに維持 |

SRAMバックアップ回路には通常電源側**MAX40200AUK+T**、電池側**BAS116系**、電圧監視**TPS3839K33DBZR**を使用する方針を維持する。CE2には100kΩ GNDプルダウンを初期候補とし、電源喪失後にも確実に非選択を維持できるか、CE1#/WE#/OE#の初期状態、SRAMの電池保持電流、各信号線からの逆給電を回路図と実測で確認する。TPS3839のプッシュプル出力だけで無給電時のCE2=Lowを保証する設計にはしない。

メモリのCE#/OE#/WE#、NOR RESET#、WP#/ACCなどは起動時の安全状態を維持するプルアップを基本に設計し、共通制御信号に重複する抵抗を設けない。具体的な結線とBOM数量は詳細回路図で確定する。PICのICSP/MCLR/VPP、PSoCのSWD/XRESは書き込み信号・基準電圧・保護の仕様を先に確定し、必要な検査パッドを残す。

## CPLDおよびレベル変換ICの電源シーケンス

AG256SL100のVDDC・VDDIO1/2・VDDF33はメーカーRev1.2資料の推奨条件どおりすべて3.3Vで供給し、SFC/PSoCの5V信号はLVC245A×5を経由する。8T245はVCCA=3.3V、VCCB=5Vとし、DIR・/OEはVCCA側の3.3Vで駆動する。両電源の立上り途中、NOR/SRAM逆給電、電源断時のIoff、AG256未構成時の制御線プルアップを検証する。

AG256のMEMアドレス15出力をHigh-ZとしてもSPECIAL_SELは維持し、microSD 3出力は独立したLVC245A #5で変換する。AG256のMEM制御4出力はHigh-Z切替せず隔離中は非選択に駆動する。AG256未起動中の/CE・/OE・/WEは外部プルアップで非選択に保持し、/RESETだけに依存しない。詳細は[cpld.md](cpld.md)。
