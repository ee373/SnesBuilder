# Rev.0.9 — 電源断時のセーブ・復元処理

## 電源断時のSRAMバックアップ

AG32 PIN24のアクティブHigh `POWER_FAIL`を受ける退避処理は**内蔵Flashに常駐する共通ファームウェア**が担当し、ゲーム固有のSRAMアプリケーションには依存しない。電源断時は退避専用スタック/割り込み状態へ移り、SFCデータバスの出力を無効にしてMEM所有権をCPUへ移行する。AG32は退避処理に必要なCPUクロックを抑え、USB・音声・microSD等の不要な処理を停止する。一方、FPGAの80 MHz BUSCLKとAHB・SPI選択デコーダは退避完了まで維持する。SDKの `SYS_SwitchHSIClock()` はPLLを停止するため、この経路での退避処理には使用しない。

外部SRAMの物理`0x00000～0x1DFFF`（120KiB）を消去済みSPI NORバンクへページ書込みし、書込み完了待機、CRC・世代番号の記録、保存完了マーカーの最終確定まで実施する。旧バンクは新バンクの保存完了まで保持する。内蔵FlashやmicroSDへ電源断セーブデータを書き込まない。電源断後のFlashコード実行と内蔵SRAM/スタック、FPGA/AHB、必要なメモリの給電維持はHiCAP動作条件に含める。

HiCAP充電完了監視や充電完了までの起動待ちは設けない。電源断割り込みとMEM所有権の順序、電源復帰時の遷移、最悪保存時間・保持時間、Flash常駐退避コードの独立性、SFC側無給電時の逆給電を実機で検証する。

65C816がセーブSRAMへ書き込んでいる最中にPOWER_FAILが入った場合、その進行中の書込み結果とゲームセーブの整合性は保証対象外とする。FPGAはSFC側のバッファとSRAM書込みを停止し、バスを隔離してからCPUに所有権を渡す。この切替時のバス競合・逆給電・端子電圧は実機で確認する。

回路・充電・しきい値は[電源・POWER_FAIL検出](../hardware/power.md)、128 KiB×2バンクのSPI NOR物理構成は[セーブストレージ](../hardware/save-storage.md)、所有権とBUS_CONTROLの解除手順は[FPGAバス](../fpga/bus.md)を参照する。
