# Rev.0.9 電源・バックアップSRAM・CIC

SFC +5VからMCP1825S-3302E/DBによって3.3Vを生成する。AG32、NOR、SRAM、microSD、U1～U4/U6、U5 VCCBへ供給し、U5 VCCA=5Vとする。入口バルクCL32A476KOJNNNE 47µF/16V、LDO入出力4.7µF、IC近傍0.1µFなどを配置する。AG32のVBAT/VDDA/VREFPと8MHz水晶はメーカー指定の接続とする。

SRAMにはMAX40200AUK+T、BAS116、TPS3839K33DBZR、CR2032と電池ホルダーを用い、電源断のCE1/CE2/WE禁止および逆給電防止を検証する。U1/U6の/OEは3.3Vプルアップ、U5 /OEは5Vプルアップ、NOR/SRAM制御は非選択プルアップとする。SFC /RESET端子26は5V⇄3.3V双方向オープンドレイン変換回路でAG32 PIN7へ、SFC /IRQ端子18はAG32 PIN26からLow駆動回路へ接続する。AG32 NRST PIN14とSFC /RESETは独立信号とする。

CICはPIC12F629-I/SNとSuperCIC Keyを採用しSFC端子24/25/55/56へ接続する。ICSP、SWD、UART0、BOOT0/1はテストパッドへ引き出す。AG32 CPU＋FPGA同時動作時とNOR書込み時のLDOピーク電流を測定する。
