# Rev.0.9 将棋AI実証

65C816側の表示・操作・進行を使用し、思考エンジンをAG32VF407VGT6のRISC-Vへ移す。FPGAの`$5001 COMMAND`、`$5005 TX_DATA`、`$5006 RX_DATA`とIRQによる通信とCPU演算を組み合わせる。`$5000 CPU_CONTROL`はゲーム固有RISC-V処理の停止・再開を制御する。NOR8MiBにはSFC側ROM・圧縮評価関数、CPU SRAM128KiBにはAccumulator・探索、外部SRAM128KiBには補助探索・セーブを配置する。USB経由でPC将棋エンジンを利用する段階も設ける。既存ゲームの解析・配布条件を確認する。

## Rev.0.9のCPU変更による強化方針（2026-11-20）

旧PSoC 5LP（Cortex-M3最大80MHz）からAG32VF407VGT6（RV32IMAFC最大248MHz）へ変更したため、CPU動作周波数の公称比は約3.1倍となった。これは実測NPSや棋力の倍率を意味しないが、思考エンジンへ割り当てられる演算性能とCPU内蔵SRAMの容量（現行128KiB）が増したことを踏まえ、従来計画以上の探索深化・評価改善を目指す。

SFC側は既存森田将棋をベースとした盤面表示・操作・進行を維持し、思考ルーチンのインターフェースを置換してRISC-Vへ委任する。RISC-Vは将棋AIの探索・評価を直接実行し、Jet/cmixerの作業領域を要求しない。まず通常の整数評価関数とαβ探索（反復深化、置換表、手の順序付け、静止探索など）を実装・最適化し、棋力と処理速度の基準値を取得する。その後、圧縮NNUE評価関数と差分更新を導入し、同一局面・同一思考時間における改善効果を測定する。

高性能化の評価はNPSだけでなく、探索深さ、固定時間での着手品質、一定条件での対局成績を比較する。USBによるPC思考エンジン連携はプロトコル検証と参照結果の比較に利用し、最終的にはAG32単体で思考を完結できることを目標とする。ゲーム本体の既存素材・プログラムの利用／配布条件は引き続き確認する。
