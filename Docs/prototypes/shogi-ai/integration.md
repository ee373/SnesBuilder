# Rev.0.9 将棋AI SFC/RISC-Vインターフェース

SFC $5000の64アドレス通信窓を使用し、COMMAND=00、STATUS=01、REPLY=02、BUS_CONTROL=03、TX_DATA=04、RX_DATA=05、FIFO_STATUS=06、IRQ_CONTROL/STATUS=07/08、LENGTH=09/0A、ERROR=0Bの構成を利用する。AI_INIT、AI_SET_POSITION、AI_MAKE_MOVE、AI_SEARCH、AI_STOP、AI_GET_BESTMOVE、AI_GET_SCORE、AI_SET_LEVELを論理コマンドとして実装する。CPU MEM使用中はWRAM待機と[bus.md](../../bus.md)の共有データバス調停に従う。
