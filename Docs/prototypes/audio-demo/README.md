# Rev.0.9 ステレオPCM・ソフトウェアDSP・3次1bit DSM音声デモ計画

更新: 2026-11-20。状態: **実装計画（RTL未合成・実機未測定）**。[Rev.0.9追加音声仕様](../../audio.md)に基づき、SFC標準SPC700/S-DSPの8chと独立したカートリッジ音源を実証する。

## デモ構成

RISC-Vはゲーム固有の音源コードを内蔵SRAM上で実行し、16bit/64kHzのステレオPCMを生成する。FPGAは5倍線形補間（64→320kHz、内部19bit）、64タップ対称FIR（320kHz）、25倍線形補間（320kHz→8MHz）、左右独立3次1bit DSMを処理する。FIRは96MHz演算クロックを使用し、係数は符号付き12bit、左右共用の20×12bit・4bit逐次乗算器1基と約40bitアキュムレータで処理する。DSM出力は水晶由来8MHzでタイミングを固定し、PIN29/30から受動RC、約22kHzのアクティブLPF、MCP6002を経てSFC AUDIO L/Rへ出力する。

FPGA内では係数対称性を利用して片ch当たり32乗算、左右合計64乗算/320kHz周期とする。96MHzでの300クロック枠に収まるか、4bitずつ3段の部分積、RAM読出し、先行加算、丸め、制御を含めてサイクル検証する。8MHz HSEのFPGA供給と96MHz PLLの供給経路、CDCも合成・実機で確認する。

## 実装段階

| 段階 | 内容 | 完了条件 |
|---|---|---|
| A0 | PIN29/PIN30をFPGA出力に割当、HSE由来8MHz、左右独立3次DSMの基本モデルと64kHzサンプル更新を準備 | ピン配置、クロック供給、ビット列、DSM安定性・過入力復帰を確認 |
| A1 | 5倍線形補間、64タップFIR、20×12bit・4bit逐次乗算器、25倍線形補間、CDCを統合 | 96MHz STA、320kHzの300クロック枠、モデル照合、LUT/FF/BRAM使用量を確認 |
| A2 | 受動RC＋約22kHzアクティブLPF＋MCP6002を調整 | 26kHzまでの総合応答、38kHz以上のイメージ、SNR/SINAD/THD+N、左右分離、8MHz残留ノイズを測定 |
| A3 | 8ch PCMミキシング、音量・パン、SFC $5000通信による制御 | 64kHzでの連続再生、IRQ/FIFO、CPU占有率、アンダーランを測定 |
| A4 | 最大16ch、多バンドEQ、ローパス/ハイパス、ディレイ/リバーブ/コーラス/リミッタ | 音声負荷とRAM・外部MEM帯域を計測 |
| A5 | SFC標準8chとの同時再生、ゲーム場面に応じた音源操作、USB/microSDリソース供給 | SFC処理と独立音声の並行動作を確認 |

A3以降の同時音源数・DSP同時稼働数はCPU負荷とRAM容量を測定して確定する。長時間の音声は内蔵SRAM128KiBへの全量保存を前提にせず、外部NOR/SRAMアクセスではSFC共有MEMバスを調停する。

## 体験と測定

画面には各音源のパン、同時音数、EQ設定、PCM FIFO残量、CPU負荷を表示し、SFC側からRISC-Vに設定を送信する。16bit/64kHzステレオPCMの1秒分は256,000Bであり、音源と遅延バッファの容量管理を明示する。

1. 無音、低振幅・最大振幅の正弦波、周波数スイープで3次DSMの安定性と高周波ノイズを測る。
2. 12bit量子化FIR係数、19bit信号幅、丸めの影響をソフトウェアモデルとRTLで比較し、補間・FIR・アナログLPFを合成した周波数特性を確認する。
3. DSM出力エッジの周期とクロックジッタ、左右同期、96MHz→8MHzのCDC、PCMのアンダーラン/復帰を測定する。
4. 実アプリで8ch/16ch、多バンドEQ、エフェクトとSFC画面更新を並行動作させ、性能を評価する。

基礎ROMマッピング・AHB通信・外部MEM所有権とFastROMの動作を優先し、DSPの仕様は[音声基本仕様](../../audio.md)に従う。
