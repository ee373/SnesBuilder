# Rev.0.9 BOMと製造計画

4層・板厚1.2mm FR-4・SFCエッジENIG、外部リード付きSMDによる手はんだ試作を採用する。

| 用途 | 型番 | 数量 |
|---|---|---:|
| SoC | AG32VF407VGT6 | 1 |
| アドレス・制御＋外付け3SB | 74LVC245APW,118 | 5 |
| 共通データ双方向変換 | SN74LVC8T245DBR | 1 |
| NOR | S29GL064S70TFI023 | 1 |
| SRAM | CY62128EV30LL-45SXI | 1 |
| 音声アンプ | MCP6002 | 1 |
| CIC | PIC12F629-I/SN | 1 |
| LDO | MCP1825S-3302E/DB | 1 |
| SRAM電源・保持 | MAX40200AUK+T、BAS116、TPS3839K33DBZR、CR2032 | 各1 |
| ESD | USBLC6-2SC6、USBLC6-4SC6 | 各1 |
| スロット | MEM2075-00-140-01-A | 1 |
| ホルダー | Keystone 3034 | 1 |
| その他 | 8MHz水晶、CL32A476KOJNNNE、MLCC、USB、MOSFET、LPF、抵抗 | 回路図確定時 |

原価はAG32・MCP6002を含むRev.0.9の数量で再見積もりし、他の構成の試算額をそのまま転載しない。未実装PCB2,980円、実装済み9,980円、ケース付き14,980円は希望税込価格として維持するが利益計算ではない。
