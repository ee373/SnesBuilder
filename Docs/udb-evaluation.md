# UDB資源評価

Rev.0.7 / 2026-11-16。設計予算でありCreatorの論理合成・配置配線結果ではない。

## 1. Rev.0.7の資源予算

| 機能 | PLD | マクロセル | 積項 |
|---|---:|---:|---:|
| 基本バス調停・メモリ・メールボックス | 18 | 67 | 107 |
| ROMミラーリング追加 | 約2 | 4 | 11 |
| 双方向FIFO制御 | 8～11 | 24～32 | 40～56 |
| 通信レジスタ拡張 | 4～6 | 10～16 | 25～40 |
| 追加制御・CDC・保護 | 2～3 | 5～8 | 8～16 |
| SPIを除く合計 | 34～40 | 110～127 | 191～230 |
| 搭載数 | 48 | 192 | 384 |

SPIを除くとPLD 70.8～83.3%、マクロセル57.3～66.1%、積項49.7～59.9%。データパス2/24、Control 7個、Status 4個、DMA原則2/24。PLD 8～14、マクロセル65～82が残る予算。ROM変換式4出力11積項（x生成・共有やSRAM保持の実装により変動）は概算であり、4マクロセル増加の保証ではない。基本RTLと追加回路間の共通化/CDC・クロック配置によって消費数は変化する。

microSD SPIを高速UDBコンポーネントで追加する場合はPLD 5～7、MC18、積項25～35、datapath1、Control1、Status3を追加する設計予算とし、全体でPLD39～47、MC128～145、積項216～265、datapath3、Control8、Status7、DMA2～4を見込む。固定機能SPIは存在しないため、資源・タイミングが不足する場合はARMによるソフトウェアSPIを使用する（UDB追加なし）。メモリ、通信、FIFOを優先する。ピン配置はどちらも共通。

## 2. 構造評価の前提

基本バス調停・メモリ・メールボックスの資源予算は18 PLD、67マクロセル、107積項を基準とする。追加機能の資源は完全なRev.0.7 RTLの合成値ではなく構造別の概算である。FIFOの記憶は専用データパスを使用し、汎用PLDで全FIFOを実装しない。

通信は32アドレス中12レジスタを初期実装、残り20は予約。各方向4byte FIFO、一時保持、DMA、CDC、エラー制御を含む。GPIO/DSI、端子OE、クロック・リセット配置、USB専用回路などの相互制約はCreatorで確認する。

## 3. 今回の検証

全100端子のCSV行数、端子番号の一意性、72 I/O、予備ゼロを確認した。実際のSRAM選択条件と電気動作、Creator合成・配置配線、STA、CDC、FIFO連続DMAは未検証である。検証コードは[verilog/README.md](verilog/README.md)に記載し、仕様の正本はhardware.md、memory.md、bus-udb.md、communication.mdとする。

## Rev.0.7 1MiB単位ミラーリング評価

ROM上位容量変換は3bit（A20～A22）で実装し、A19は74LVC16244の専用チャネルを経由してメモリへ接続する。Rev.0.7では1～4MiB HiROM、1～8MiB ExHiROM、A23/A21/A20/A19の全組合せおよびRAM選択状態を含む384条件について、論理式を再現したPython実装と独立再帰ミラーモデルの一致を確認した（PASS 384/384）。VerilogテストベンチとRTL本体は提供するが、HDLコンパイル・シミュレーションは未実行。設計予算34～40 PLD等は旧推定値のままであり、Rev.0.7の実測使用量ではない。音声用DVDAC・DMA・タイマー資源はこの見積りに含まれない。[verilog/README.md](verilog/README.md)参照。
