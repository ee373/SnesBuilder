# Rev.0.9 電源・不揮発性セーブバックアップ・CIC

## 電源構成

SFCカートリッジ端子の生5Vを `SFC_5V_RAW` とし、TI LM66100DCKR（SFC側逆流防止）を経由した内部5Vを `SYS_5V` とする。MCP1825S-3302E/DB（SOT-223、3.3V／500mA）を維持し、`SYS_5V` から3.3Vを生成する。AG32、外部8MiB NOR、128KiB SRAM、256KiB SPI NOR、microSD、U1～U4/U6およびU5の3.3V側へ給電する。U5の5V側はSFC側給電と電源断時の分離条件を満たすよう接続する。入力バルクCL32A476KOJNNNE（47µF/16V）、LDO入出力4.7µF、各IC近傍0.1µFなどを設ける。AG32のVBAT/VDDA/VREFPおよび8MHz水晶はメーカー指定の接続を守る。

## HiCAPの充放電

| 用途 | 採用部品・定数 | 数量 |
|---|---|---:|
| 蓄電 | Cornell Dubilier DGH105Q5R5、5.5V・1F | 1 |
| SFC側逆流防止 | TI LM66100DCKR | 1 |
| HiCAPから内部5Vへの放電経路 | TI LM66100DCKR | 1 |
| HiCAP充電電流制限 | 47Ω・1W | 1 |
| 3.3V LDO | Microchip MCP1825S-3302E/DB | 1 |

接続は `SFC_5V_RAW → LM66100 → SYS_5V → MCP1825S → 3.3V` とし、`SYS_5V → 47Ω → HiCAP+` で充電する。HiCAP+から別のLM66100（VIN側=HiCAP、VOUT側=SYS_5V）を経由して`SYS_5V`へ給電することで、放電電流が47Ωを経由しないようにする。HiCAP−はGNDへ接続し、SFC側への逆給電を最初のLM66100で防ぐ。両LM66100のCE/STの扱いと電源投入・遮断時の挙動はデータシートに従って回路図で確定する。

47Ω充電時の理論初期電流は5V/47Ω≒106mA、抵抗の初期損失は約0.53W。1Fを0Vから充電する理想RC計算では4.5V到達まで約108秒、4.8Vまで約151秒となる。充電完了監視および充電完了までの起動待ちは設けず、初回使用時・長期間未使用後は電源投入から約3分程度経過してから電源を切る旨を取扱説明に明記する。

DGH105Q5R5は公称1F、5.5V、1kHz ESR約0.28Ωのラジアル型を使用し、PCB端部の切り欠き内に横向き実装して厚さ方向を約8.5mmとする。17×16×8.5mmの本体寸法、リード位置、ケース内リブとの干渉を機構図で照合し、リードのみで荷重を受けない固定を設ける。許容電圧の温度ディレーティング、DC ESR、容量下限を保持時間の計算に含める。

## 電源断検出

安価な単回路コンパレータ LMV331W5-7 を1個使用する。コンパレータVCCと出力プルアップはHiCAPによって保持される3.3Vへ接続し、監視対象は逆流防止より前の `SFC_5V_RAW` とする。コンパレータは`IN+=3.3V基準分圧点`、`IN−=SFC_5V_RAW監視分圧点`とし、電源低下時にオープンコレクタ出力がHighへ解放される`POWER_FAIL`（アクティブHigh）をAG32へ通知する。

| 部品・用途 | 定数 | 数量／実装 |
|---|---|---|
| 生5V監視分圧・上側 | 330kΩ | 1／実装 |
| 生5V監視分圧・下側 | 180kΩ | 1／実装 |
| 保持3.3V基準分圧・上側 | 100kΩ | 1／実装 |
| 保持3.3V基準分圧・下側 | 100kΩ | 1／実装 |
| コンパレータ出力プルアップ | 100kΩ（3.3V） | 1／実装 |
| ヒステリシス正帰還 | 抵抗値はしきい値計算後に確定 | 1／実装 |
| 生5V監視分圧点のRCパッド | 4.7nF（GND間） | 1／初期未実装（DNP） |
| 基準電圧分圧点の追加コンデンサ | 設けない | — |
| LMV331電源デカップリング | 0.1µF | 1／実装 |

基準電圧は公称1.65V、生5V監視の分圧係数は180/(330+180)で、ヒステリシスを含まない理論検出電圧は約4.675V。正帰還抵抗は出力プルアップと基準分圧抵抗を含む実回路で再計算し、電源断と復帰のしきい値を設定する。基準側はLDO出力とLMV331近傍のデカップリングで安定化し、分圧点にコンデンサは追加しない。監視側4.7nFはパッドだけを用意し、実機で必要な場合のみ実装する。

AG32 PIN23はSPI NORの専用/CS、PIN24は`POWER_FAIL`入力、PIN25は予備。セーブ用SPI NORとmicroSDはCPUのSPI0を共有する。CPUはGPIO6 bits3:2に選択値を書き、FPGAのデコーダが対応する /CS を駆動する。RISC-V側の接続は[FPGA実装仕様](../fpga/README.md)を参照する。

## 電源断後のバックアップ動作

外部128KiB SRAMの物理0x00000～0x1DFFF（120KiB）をセーブ対象とし、0x1E000～0x1FFFFの8KiBはSFC用BIOS領域として退避しない。専用256KiB SPI NOR（GD25Q20ETIGR）はmicroSDとSCK/MOSI/MISOを共有し、独立した/CSを持つ。128KiB×2バンクに分割し、各バンクには120KiBのデータと世代番号・CRC・保存完了マーカー等を記録する。

起動時は両バンクの管理情報とCRCから最新の正常な世代を選んでSRAMへ復元し、続いて使用していない側のバンクを消去して次の電源断に備える。保存先バンクの消去を通常給電中に終えておき、電源断後は消去操作を実行しない。

`POWER_FAIL`検出後、AG32はSFCバス出力を停止し、FPGAのMEM所有権FSMに従ってCPU側へ移行する。CPUの退避専用処理を優先してUSB・音声・microSDなど不要な処理を停止する。FPGAの80 MHz BUSCLKとAHB・SPI選択デコーダは維持し、PLLを停止するAgRV SDKの `SYS_SwitchHSIClock()` は退避中に使用しない。FPGA/AHB経由でSRAMを読み、SPI NORの消去済みバンクへページプログラムし、書込み完了を確認してCRC・世代番号を検証する。全データ保存後に保存完了マーカーを最後に確定する。旧バンクは新バンクの正常確定までは消去せず保持する。バックアップ完了後はCPUとFPGAの処理を停止する。

電源断中に必要なAG32・FPGA・SRAM・SPI NORおよびメモリバス制御が保持3.3Vで動作できることを前提とする。U5のSFC側5Vドメイン、U1～U4のSFC入力側、外部NOR等の非選択制御において、無給電SFC側への逆給電・バス競合が発生しないようハードウェアで規定する。電源断直前のSRAM更新競合、セーブ所要最大時間、起動時バンク消去、保持時間および電源復帰時の遷移を試作で検証する。

65C816がセーブSRAMへ書き込んでいる最中にPOWER_FAILが入った場合、その進行中の書込み結果とゲームセーブの整合性は保証対象外とする。FPGAはSFC側のバッファとSRAM書込みを停止し、バスを隔離してからCPUに所有権を渡す。この切替時のバス競合・逆給電・端子電圧は実機で確認する。

退避中に電源が復帰しても、FPGAはCPUのMEM所有権と電源断割り込みを保持する。RISC-Vは退避を完了し、POWER_FAILが解除されたことを確認してから、BUS_CONTROL bit5への1書込みで保持を解除する。

## SFC制御・CIC

U1/U6の/OEは3.3Vプルアップ、U5の/OEは安全側プルアップ、NOR/SRAM制御は非選択プルアップとする。SFC /RESET端子26は5V⇄3.3V双方向オープンドレイン変換回路でAG32 PIN7へ、SFC /IRQ端子18はAG32 PIN26のLow駆動回路へ接続する。AG32 NRST PIN14とSFC /RESETは独立する。CICはPIC12F629-I/SNとSuperCIC Keyを採用してSFC端子24/25/55/56へ接続する。ICSP・SWD・UART0・BOOT0/1をテストパッドへ引き出し、AG32＋FPGAの高負荷時とNOR書込み時のMCP1825S最大出力電流・温度を測定する。
