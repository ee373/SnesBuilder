# Rev.0.9 将棋AI実証工程

| 段階 | 完了要件 |
|---|---|
| M0 | 元ROMの呼出し/盤面/ABIを解析 |
| M1 | $5001 COMMANDと$5005/$5006 FIFOで固定合法手を返し、$5000 CPU_CONTROLの停止・再開を確認 |
| M2 | USB Full-Speed経由でPC思考エンジンと連携 |
| M3 | AG32のRISC-Vで合法手生成・探索を単体実行 |
| M4 | 整数評価・NNUEをPC参照と照合 |
| M5 | 圧縮評価関数をNORから部分復号 |
| M6 | NPS、思考時間、棋力を計測 |

本体のROM/FIFO/AHB/共有MEM所有権制御は現行AG32向けFPGA RTLに実装済みである。まず実機でSFC↔RISC-V通信とバス返却を確認し、その後に将棋ソフトウェアを接続する。

## Rev.0.9高速化に伴う測定・改善項目（2026-11-20）

M3では、AG32のRISC-V上で通常の整数評価関数と探索を先行して成立させ、合法手生成、反復深化・αβ探索、置換表、静止探索を段階的に評価する。現行FPGA構成と一致するCPU SYSCLK 240MHzでNPS・探索深度・消費SRAMを実測して比較する。

M4～M5では、通常評価関数版を基準にNNUE導入による棋力・NPSの変化を測定し、差分Accumulatorと圧縮重みのNOR部分復号についてCPU SRAM消費量・共有8bit MEMアクセス量・探索中の待機時間を記録する。FPGA INT16×4 MACはロードマップ上の任意ストレッチ目標として、転送を含む高速化が見込めた場合にのみ比較検証する。

M6では同一局面集、同一持ち時間・探索制限でNPS、到達深さ、着手時間、対局勝率などを測定し、通常評価版、NNUE版、必要に応じたFPGAアクセラレータ版を比較する。USB連携のPCエンジンは正当性・性能比較の参照に使用し、最終的な思考処理はAG32単体で完結させる。
