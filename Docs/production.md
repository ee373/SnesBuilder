# Rev.0.9 AGM構成のBOMと製造計画

本書のBOMはAG32VF407VGT6・LQFP100と現行[ピン配置](pinout.csv)を対象とする。FPGA本番RTLの合成・配置配線は実施済みだが、基板製造と実機電気特性の検証は別工程である。

4層・板厚1.2mm FR-4・SFCエッジENIGを使用し、手はんだ試作を基本とする。基板端部に5.5V・1F HiCAPを横向きで納める切り欠きを設け、ケースのリブ・基板固定位置と干渉しないか現物で確認する。

## 電源・保存動作

従来の電池保持部品は使用せず、外部SRAMのセーブ対象120KiBをAG32が電源断時に専用SPI NORへ保存する。SPI NORは128KiB×2バンク構成とし、起動時に正常な最新世代をSRAMへ復元して未使用バンクを消去する。電源断時はHiCAPからMCP1825Sへ給電し、AG32低クロックRunで退避処理を実行する。回路上の配線・動作条件は[power-cic.md](power-cic.md)、メモリ領域は[memory.md](memory.md)を正本とする。

## 原価・製造

AG32VF407VGT6、現行SRAM、HiCAPとセーブ用SPI NORを含む暫定部品予算は約3,380～3,630円/枚（100枚想定）とする。PCBは従来の500～1,200円/枚に切り欠き加工条件を反映して見積もる。数量単価未確認のLY62W1024SL-55SLIは暫定予算350～500円/枚とし、部品価格・在庫・基板加工費・組立工賃は発注前に見積り直す。

未実装PCB2,980円、実装済み9,980円、ケース付き14,980円の希望税込価格は維持するが利益確定値ではない。
